💼 KerjaKu API

API statis berisi data lowongan kerja aplikasi KerjaKu, diekspor dari backend Node.js (Express). Semua data berupa file JSON, bisa diakses langsung tanpa login.

Daftar Endpoint

1. Semua Lowongan
GET /api/jobs.json
2. Detail Lowongan
GET /api/jobs/[ID].json

3. Daftar Lokasi
GET /api/locations.json
4. Lowongan per Lokasi
GET /api/locations/[CODE].json
